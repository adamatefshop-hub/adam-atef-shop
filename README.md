## ⚡ Comment Mettre en Ligne sur GitHub Pages en 2 Minutes

Avec votre compte GitHub associé à `adam.atefShop@gmail.com` :

### Méthode 1 : Via l'interface web GitHub (Recommandé)
1. Connectez-vous sur [GitHub.com](https://github.com) avec `adam.atefShop@gmail.com`.
2. Cliquez sur **New Repository** (Nouveau dépôt), nommez-le par exemple `shop` ou `store`. Assurez-vous qu'il soit **Public**.
3. Cliquez sur **Upload files** (Téléverser des fichiers) et glissez-déposez tous les fichiers du dossier `digital-store/` :
   - `index.html`
   - `config.js`
   - `products.js`
   - `app.js`
   - le dossier `assets/` avec les 5 images
4. Validez en cliquant sur **Commit changes**.
5. Allez dans l'onglet **Settings** du dépôt > section **Pages** (dans le menu de gauche).
6. Sous **Branch**, sélectionnez `main` (ou `master`) et `/ (root)`, puis cliquez sur **Save**.
7. En moins de 60 secondes, votre site sera accessible gratuitement dans le monde entier à l'adresse :  
   `https://<votre-pseudo-github>.github.io/<nom-du-repo>/`
